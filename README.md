## 커밋 메세지 및 파일 수정

### 로컬에서 커밋했지만, 원격에 푸쉬하지 않은 경우

1. 파일 수정 및 저장

2. 변경사항 스테이징
    - 명령어 사용할 경우 터미널에 아래의 명령어 입력
    ```
    git add 수정한파일명
    ```

3. 커밋 메세지 수정을 위해 터미널에서 아래의 명령어 입력
    ```
    git commit --amend
    ```

4. 커밋 메세지 편집 창에서 메시지 수정 후 저장 및 종료

5. 이후 원격에 푸쉬하면 됨

### 원격에 푸쉬한 경우

1. 파일 수정 및 저장

2. 변경사항 스테이징
    - 명령어 사용할 경우 터미널에 아래의 명령어 입력
    ```
    git add 수정한파일명
    ```

3. 커밋 메세지 수정을 위해 터미널에서 아래의 명령어 입력
    ```
    git commit --amend
    ```
4. 커밋 메세지 편집 창에서 메시지 수정 후 저장 및 종료

5. 이후 강제 푸쉬를 위해 터미널에 아래의 명령어 입력
    ```
    git push --force
    ```
